# Julius Remodeling Group website

A static site: `index.html` (home), `condo-remodeling.html` (condos & apartments), shared `site.css` and `site.js`, and an `assets/` folder. It has no build step and no dependencies.

## Add your business details

Open `site.js` and fill in the `CONFIG` block at the top. Both pages (`index.html` and `condo-remodeling.html`) read from it:

```js
var CONFIG = {
  phone: "(425) 699-9636",
  email: "hello@juliusremodeling.com",
  license: "JULIURG000AB",
  insurance: "Fully insured · $2M general liability",
  hours: "Mon–Fri 8am–6pm",
  formEndpoint: ""   // see "Contact form" below
};
```

Every placeholder on the page (header, hero, contact cards, footer) updates automatically.

## Contact form

The form sends nothing until `formEndpoint` is set.

1. Create a free form at https://formspree.io and copy its endpoint (`https://formspree.io/f/xxxxxxx`).
2. Paste it into `formEndpoint`.
3. Submissions arrive in your inbox. Without an endpoint, visitors see their request and a button to copy it.

## Deploy

```bash
cd ~/Desktop/Apps/"Julius Remodeling"
git init && git add . && git commit -m "Julius Remodeling Group website"
gh repo create julius-remodeling --private --source=. --push   # or create the repo on github.com and push
```

Then on https://vercel.com: **Add New → Project → Import** the repo. Framework preset: **Other**. Leave the build command and output directory empty. Deploy.

After you connect your domain in Vercel, change `og:image` in `index.html` to the full URL (for example `https://juliusremodeling.com/assets/logo.jpg`) so link previews show the logo.

## Project photos

The three project cards show line drawings for now. To use photos, put them in `assets/` and replace each `<svg>` inside `.proj .frame` with:

```html
<img src="assets/condo.jpg" alt="Downtown condo living room after renovation" style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover">
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The full site: content, styles, and scripts |
| `404.html` | Page shown for unknown URLs |
| `assets/` | Logo, wordmark, favicon, touch icon |
| `vercel.json` | Clean URLs, asset caching, security headers |
| `robots.txt` | Allows search engines to index the site |

## Service pages

Every service page except `condo-remodeling.html` (kitchen, bathroom, basement, whole home, flooring, interior finish, doors, windows, stairs, concrete, drywall) is generated by `tools/build-pages.rb`, which also refreshes the header (Services dropdown) and footer on `index.html`, `condo-remodeling.html`, and `consultation.html`. Edit the page content in that script, then run:

```sh
ruby tools/build-pages.rb .
```

The consultation page (`consultation.html`) holds the GoHighLevel form. It is not in the menu and is hidden from search engines; every "Free consultation" button links to it.
